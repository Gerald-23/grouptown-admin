# Grouptown Firebase

Shared Firebase workspace for the Grouptown mobile and web clients.

## Purpose

This folder is for Firebase project-level configuration and backend conventions.

- `auth` auth notes and provider decisions
- `firestore` collection design and indexes
- `storage` upload path design and storage rules notes
- `functions` privileged backend logic
- `rules` deployed Firebase security rules
- `emulators` local emulator guidance
- `docs` architecture notes shared across clients

## Suggested next steps

1. Add Firebase project ids and environment conventions
2. Define the Firestore collections and user roles
3. Write auth, Firestore, and storage rules before production data entry
4. Add Cloud Functions only for privileged or complex workflows
